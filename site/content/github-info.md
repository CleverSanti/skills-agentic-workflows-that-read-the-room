## Recent GitHub Updates (October 2026)

- **Triage role users or higher can now archive pull requests** ([Changelog, 2026-10-08](https://github.blog/changelog/2026-10-08-triage-role-users-or-higher-can-now-archive-pull-requests))
  - Users with the triage role or higher can now archive and unarchive pull requests, making repository management more flexible.

- **Claude Haiku 5.5 now available in GitHub Copilot** ([Changelog, 2026-10-07](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot))
  - Anthropic’s Claude Haiku 5.5 model is now generally available in Copilot, offering faster, high-volume AI assistance for coding and terminal tasks.

- **ReviewBench: Open benchmark for AI code review** ([Blog, 2026-10-05](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/))
  - GitHub launched ReviewBench, a benchmark for evaluating AI code review agents using real pull requests and production-aligned metrics.
