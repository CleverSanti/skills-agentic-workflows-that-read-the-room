## Recent GitHub Updates (as of 2026-10-08)

- **Claude Haiku 5.5 now in GitHub Copilot**: Anthropic’s Claude Haiku 5.5 model is now generally available in GitHub Copilot, optimized for fast, high-volume tasks like subagents and quick edits. [Source: GitHub Changelog, 2026-10-07](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot)
- **Draft pull requests now count toward PR limits**: Maintainers can configure pull request limits to include draft PRs, helping manage low-quality contributions. [Source: GitHub Changelog, 2026-10-08](https://github.blog/changelog/2026-10-08-draft-pull-requests-count-toward-pull-request-limits)
- **Triage role users can archive pull requests**: Users with the triage role or higher can now archive and unarchive pull requests, not just admins. [Source: GitHub Changelog, 2026-10-08](https://github.blog/changelog/2026-10-08-triage-role-users-or-higher-can-now-archive-pull-requests)
- **ReviewBench: Open benchmark for AI code review**: GitHub launched ReviewBench, a benchmark for evaluating code review agents using real PRs and production-aligned metrics. [Source: GitHub Blog, 2026-10-05](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)
